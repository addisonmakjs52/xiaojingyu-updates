# 小鲸鱼

Windows 上的 DeepSeek QQ 文字聊天客户端，包含完整人格、本地长期记忆、图片分析与蓝色桌面界面。

## 当前发行状态

1.4.0 已完成本机升级与离线验证。发行附件尚未上传，公网更新暂未启用；请以 Releases 中正式发布的附件为准。

[进入下载与更新页面](https://github.com/addisonmakjs52/xiaojingyu-updates/releases)

## 已安装用户

首次接入客户端更新需要从 1.3.3 升至 1.4.0：停止并关闭小鲸鱼 → 双击小型升级 EXE → 选择原安装目录 → 升级并打开 → 保存并启动。

以后使用左下角「检查更新」，有新版时确认下载即可。运行环境未改变时，不重复下载 Python、Ollama 和记忆模型。

## 新电脑

小型升级包不包含完整运行环境。请先安装提供给你的 1.3.3 完整安装包，再运行 1.4.0 升级包。

## 数据与更新

- Key、人格、QQ 登录文件和长期记忆保存在自己的电脑，不上传此仓库。
- 更新仅替换 app 中的清单文件，保留 data。QQ 登录过期时仍需本人扫码。
- 下载校验失败不安装。文件替换失败支持恢复；中断后关闭程序并重新运行升级包。
- 安装包尚未进行商业代码签名。

维护者发布时必须同时上传升级 EXE、update.json 和对应说明。每个版本声明兼容范围，并先验证升级、失败恢复和个人数据保留。不要上传正在使用的安装目录。
